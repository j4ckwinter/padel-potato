### Primitive API Boundaries

- Public variant and state props are closed TypeScript unions. Unsupported runtime values must fail explicitly in development and tests; they must not silently fall back.
- Every visual semantic is named by an existing token. Numeric spacing, colours, typography metrics, radius, border width, opacity, icon size, and control height are not accepted as arbitrary public values.
- Each primitive may expose a narrowly typed React Native `style` escape hatch for layout or platform correction. Token-owned properties are excluded:
  - `Text`: no `fontFamily`, `fontSize`, `fontWeight`, `fontStyle`, `lineHeight`, `letterSpacing`, or `color` overrides.
  - `Stack` and `Inline`: no `gap`, padding, or `flexDirection` overrides.
  - `Surface`: no `backgroundColor`, border colour/width/radius, or shadow/elevation overrides.
  - `Icon`: no raw SVG paint, path, viewBox, width, or height overrides.
  - `Pressable`: no override that removes the minimum hit target, focus indication, state opacity, or disabled/loading behavior.
- Standard React Native accessibility props pass through. Defaults are supplied only where the primitive has inherent semantics.
- No primitive imports Penpot, navigation, storage, networking, product models, or product copy at runtime.

## Spacing Scale

### Active Phase 2 presentation scale

The Phase 2 primitive and catalogue defaults use the standard presentation scale `4, 8, 16, 24, 32, 48, 64`, limited as follows by the authoritative token inventory:

| Scale step | Current token | Default Phase 2 usage |
|------------|---------------|-----------------------|
| 4 | `space4` | Tight icon/text and specimen gaps |
| 8 | `space8` | Compact inline and control-internal spacing |
| 16 | `space16` | Default primitive gap and surface padding |
| 24 | `space24` | Section and grouped-content spacing |
| 32 | `space32` | Large section separation |
| 48 | Not currently authored | Unavailable; do not encode a raw literal or synthesize a token |
| 64 | Not currently authored | Unavailable; do not encode a raw literal or synthesize a token |

The exact active subset available from current Penpot tokens is therefore `4, 8, 16, 24, 32`. Values 48 and 64 are reserved presentation-scale positions only; they become usable only if a future Penpot revision adds source-traceable tokens.

## Typography

### Active Phase 2 presentation hierarchy

Phase 2 primitive documentation, catalogue labels, and default examples use exactly four sizes and two weights:

| Default role | Token | Size | Weight | Absolute line height |
|--------------|-------|------|--------|----------------------|
| Supporting | `caption` | 11 | 400 | 13.2 |

| Heading | `heading` | 18 | 700 | 21.6 |

This 11/14/18/28 and 400/700 hierarchy is the default presentation language for Phase 2. New primitive examples must select from it unless an authoritative Penpot source requires another existing token.

### Complete inherited Penpot inventory

`Text` continues to expose all nine already-verified `TypographyToken` values. None is deleted, altered, deprecated, or remapped:

| Token / role | Size | Weight | Absolute line height | Phase 2 disposition |
|--------------|------|--------|----------------------|---------------------|
| `micro` | 10 | 600 | 12 | Bounded source-dependent exception |
| `caption` | 11 | 400 | 13.2 | Active default |
| `label` | 12 | 600 | 14.4 | Bounded source-dependent exception |
| `body` | 14 | 400 | 16.8 | Active default |
| `bodyStrong` | 15 | 600 | 18 | Bounded source-dependent exception |
| `heading` | 18 | 700 | 21.6 | Active default |
| `section` | 20 | 700 | 24 | Bounded source-dependent exception |
| `title` | 25 | 700 | 30 | Bounded source-dependent exception |

Contract:

- Source-dependent exceptions may deliberately select `micro`, `label`, `bodyStrong`, `section`, or `title` only when a traced Penpot component, lockup, or retained reference requires that exact verified token. This preserves authored values without expanding the default hierarchy or inventing new typography.
- All roles use the matching static runtime family (`Inter_400Regular`, `Inter_600SemiBold`, or `Inter_700Bold`) so native platforms do not synthesize weights. The active default hierarchy itself uses only the 400 and 700 families; the 600 family remains available for source-dependent exceptions.
- `allowFontScaling` remains enabled by default. Do not impose a default `maxFontSizeMultiplier`.
- Text wraps and grows vertically by default. Single-line truncation is opt-in and must be explicit at the consuming component level.
- Large-text stories exercise at least 200% font scaling. No required action or semantic content may clip, overlap, or become unreachable.

### Icons

The closed `IconName` union contains exactly these 18 manifest records:

`add`, `back`, `calendar`, `check`, `chevron`, `clock`, `close`, `court`, `eye`, `filter`, `home`, `location`, `notification`, `overflow`, `players`, `profile`, `search`, `warning`.

| Property | Contract |
|----------|----------|
| Source | Corresponding component record under `Padel Potato / Components / Icons` in revision 292 |
| Canvas | 20×20, bound to `dimensions.iconSize20` |
| Geometry | Export from Penpot MCP as SVG; preserve path/ellipse/rectangle geometry and viewBox exactly |

### Brand lockups

| Asset | Source ID | Authored size | Contract |
|-------|-----------|---------------|----------|
| `BrandLockup` | `482a7222-5a3b-8086-8008-a61e9426c83d` | 300×72 | Preserve 25:6 aspect ratio; mascot image, 25/700 name, and 11/400 tagline; one original colourway. |

Lockups accept one sizing axis (`width`), derive height from the authored ratio, and never accept independent text, image, colour, aspect-ratio, or content overrides. ### Source traceability

- Every generated asset record contains `designName`, component `sourceId`, `sourceNodeId`, file ID, page ID, source revision 292, SVG/export SHA-256, and generator version.
- Export and normalization are deterministic. Re-running against the same Penpot revision must produce byte-identical normalized geometry or an explicit reviewed evidence change.
- Penpot manifest, exports, hashes, references, and deviations remain build evidence under `design-spec/`; runtime code imports only local assets.
- If MCP export, SVG compatibility, image extraction, source identity, or hashing cannot be proven, implementation stops. Geometry must never be redrawn or approximated.

## Interaction Contract

### Pressable state machine

| State | Visual contract | Semantic / behavior contract |
|-------|-----------------|------------------------------|
| Default | Consumer-authored token-backed content; no imposed component-family styling | `onPress` enabled; caller supplies label/role appropriate to the composed control |
| Pressed | Expose native `pressed` render state for token-backed composition | One activation per completed press; no action when disabled or loading |
| Focused | Visible 2-point `focusRing` indication that is not colour-only | Native focus preserved; focus is not synthesized as a persistent selected state |
| Disabled | `opacityDisabled` 0.4 without layout shift | `accessibilityState.disabled=true`; suppress press callback |
| Loading | Stable layout; consumer supplies bounded loading content without replacing the accessible name | `accessibilityState.busy=true` and `disabled=true`; suppress press callback |

- Authored visual control dimensions 40, 44, and 48 remain available through existing dimension tokens. The interactive target is always at least 44×44; a 40×40 visual uses symmetric 2-point hit expansion or an equivalent non-visual wrapper.
- Hit expansion must account for React Native parent bounds. Stories place controls in sufficient surrounding space and tests verify the effective target contract rather than only the visible frame.
- Loading and disabled are mutually representable states but both suppress activation. Public types must not permit a callback path that bypasses suppression.
- The primitive does not infer `button`, `link`, navigation, toggle, checked, selected, or expanded semantics. Those belong to the composed component and must be passed explicitly.
- Web hover may be exposed only as a secondary compatibility signal; it is not a required public state and must not alter native contracts.

## Storybook Contract

Every Phase 2 public export appears under `Primitives/*` or `Assets/*` and uses the shared story taxonomy below. A story is omitted only when the category is inherently inapplicable, with that reason asserted in the story-coverage test.

| Story | Required content |
|-------|------------------|
| `Canonical` | One source-faithful default specimen with source identity visible in the catalogue context |
| `Variants` | Complete bounded token/name/asset options in deterministic Penpot order |
| `States` | All applicable semantic/interaction states; mandatory for `Pressable` |
| `Boundaries` | Long text, 200% font scale, wrapping, constrained width, and asset scaling where applicable |
| `Interactive` | Action logging and state transition demonstration; mandatory only for `Pressable` |

Controls expose only closed unions and valid combinations. No free-form colour, size, SVG, arbitrary typography, or unsupported state controls are allowed. Each story renders native React Native primitives through the same CSF file on iOS, Android, and the secondary Expo-web lane.

Recommended catalogue grouping:

- `Primitives/Text`
- `Primitives/Layout` (`Stack`, `Inline`)
- `Primitives/Surface`
- `Primitives/Pressable`
- `Assets/Icons`
- `Assets/Brand`

The existing `FoundationFontGate` remains the global preview decorator. Phase 2 may add non-visual shared preview behavior only if it composes inside that gate and does not create a second font-loading boundary.

## Test and Accessibility Contract

Shared test helpers must make these checks reusable by Phases 3 and 4:

| Helper responsibility | Required assertion |
|-----------------------|--------------------|
| Role | Expected React Native accessibility role is present; no role is inferred where semantics are not inherent |
| Label | Interactive/semantic content has a stable accessible name; decorative icons are absent from the accessibility tree |
| Value | `accessibilityValue` is preserved and testable for composed controls |
| State | Disabled, busy/loading, selected, checked, expanded, and other supplied native states pass through accurately |
| Press | Enabled invokes once; disabled and loading never invoke |
| Target | Effective interactive target is at least 44×44 for 40, 44, and 48 visual sizes |
| Tokens | Public props resolve to the exact existing token objects/values; unexplained literals and raw public values are rejected |
| Variants | Closed unions and controlled runtime rejection cover unsupported values |
| Assets | Name completeness, geometry hashes, 20×20 canvas, 1.75 stroke, source IDs, revision, and lockup aspect ratios match retained evidence |
| Large text | Representative 200% scaling remains readable, wraps/reflows, and preserves every action |

Tests are behavior- and value-oriented, not snapshot-heavy. Snapshot output may supplement geometry review but cannot replace semantic, interaction, source-value, or native visual evidence.

Native assistive-technology review remains part of final Phase 5 acceptance, but this phase must establish testable roles, labels, values, states, target sizing, reading order, and large-text behavior now.
