## Trust Boundaries

| Boundary | Description |
|----------|-------------|

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering / Denial of Service | archive extraction | high | mitigate | Reuse bounded parser; pin file/page/revision/hash/set IDs/counts/order and mutation-test failures. |
| T-04-02 | Tampering / Elevation of Privilege | extraction paths | high | mitigate | Fixed tracked outputs plus resolved-root containment checks before every write/read. |
| T-04-03 | Spoofing / Information Disclosure | runtime media/source | high | mitigate | Static local/RN sources only; scan generated/runtime modules for remote/archive dependencies. |
| T-04-04 | Tampering | Avatar public props | medium | mitigate | Closed unions, own-key/scalar/tuple checks, and exact diagnostic tests. |
| T-04-05 | Repudiation | retained evidence | high | mitigate | Full source identities, hashes, deep freeze, deterministic regeneration, and byte equality. |
| T-04-NA | S/R/I/D/E | auth/session/access-control/crypto | low | accept | No credentials, sessions, authorization decisions, secrets, persistence, or application cryptography exist in this local stateless component slice. |
| T-04-SC | Tampering | package supply chain | high | mitigate | No package installation or dependency-version changes are authorized. |
